LET'S SET THINGS UP

还差一点，就准备好了。

工作空间需要管理员密码和 KV 存储。完成下面的设置，再回来登录。

  1. 设置你的管理员密码

    打开 Cloudflare 控制台，进入当前 Worker / Pages 项目的设置。在变量与机密中添加 ADMIN，类型选择机密，填入你自己的强密码。

    请把密码保存在密码管理器中，不要写入公开仓库。

  2. 创建并绑定 KV 存储

    在 Cloudflare 的存储与数据库中创建一个 Workers KV 命名空间。回到项目绑定设置，新增 KV 命名空间绑定，变量名准确填写 KV，并选择刚创建的命名空间。

  3. 保存设置，重新部署

    确认 ADMIN 和 KV 都已生效后重新部署。若使用 Pages，请同时检查生产环境绑定。部署完成后，访问 /login 输入管理密码。

第一次登录后，工作空间会在 KV 中初始化配置。节点 UUID 建议在部署环境变量中显式设置。
