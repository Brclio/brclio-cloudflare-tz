06

Cloudflare 部署变量

这些变量由 Cloudflare 在运行时提供。请进入对应 Worker 或 Pages 项目的设置，修改变量与机密后按平台要求重新部署。

本页只解释变量用途；顶部「保存配置」不会修改部署变量。HOST 和 PATH 会覆盖面板中的对应值。布尔变量用 1 或 true 启用。

变量用途填写示例 / 默认行为
ADMIN管理后台登录密码。以机密保存自己的强密码。
UUID固定节点身份，建议使用有效的 UUID v4。未配置有效值时，会根据管理密码与 KEY 派生。
KEY自定义密钥，参与 UUID 派生与快捷订阅路径。以机密保存；修改后需重新获取相应链接。
HOST覆盖节点主机名列表。node.example.com；未设置时由当前请求域名决定。
PATH覆盖节点的 WebSocket / HTTP 路径。/my-path；未设置时使用主配置。
URL根路径及非业务请求的伪装页面。nginx、1101 或站点域名；未设置时根路径进入后台。
PROXYIP指定默认反代出口；连接路径中的出口参数可覆盖。proxy.example.com:443；未设置时自动选择。
GO2SOCKS5在主配置的代理域名白名单外，强制附加域名匹配规则。*.example.com；多个规则以逗号或换行分隔。
DEBUG开启 Worker 调试日志。1 / true；默认关闭。
OFF_LOG停止写入 KV 访问日志。1 / true；默认继续记录。
BEST_SUB允许向兼容的上游请求提供优选订阅生成器输出。1 / true；默认关闭，仍需请求符合生成器条件。
PRELOAD_RACE_DIAL预加载竞速拨号。1 / true；默认关闭。
TCP_CONCURRENT_DIALTCP 直连并发拨号数量。正整数，默认 2；自动识别移动网络时可降为 1。
PROXY_CONCURRENT_DIAL反代并发拨号数量。正整数，默认 1。
