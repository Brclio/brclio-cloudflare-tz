# Brclio Edge 界面设计

## 设计方向

把管理后台做成一个日常可用的工作空间。受众是第一次部署 Cloudflare 应用的中文读者，也为熟悉上游的用户保留原始 JSON。

视觉依据是 Brclio Design System 的品牌原则：暖纸底色、蓝色主操作、黄色引导、红色危险操作；中文衬线标题搭配无衬线正文。UI、图案和文案独立实现，以满足整个程序 GPL 开源的要求。未分发设计系统的非商业模板或原作者图片。

## 信息结构

| 页面 | 内容组织 | 主要任务 |
| --- | --- | --- |
| 登录 | 不对称双栏介绍与登录表单 | 输入自己的管理员密码 |
| 概览 | 横向状态条、连接信息与步骤并排、最近活动列表 | 理解已加载的配置状态 |
| 节点配置 | 分段表单与侧边说明 | 修改协议、传输与连接参数 |
| 订阅管理 | 链接操作区、来源表单、独立地址编辑器 | 获取客户端订阅，保存优选来源 |
| 路由与代理 | 横向连接示意、参数表单 | 设置出口与代理策略 |
| 日志 | 搜索、类型过滤、分页表格 | 排查订阅与管理操作 |
| 设置 | 可选服务、备份区、JSON 折叠编辑器 | 维护和恢复配置 |

导航在桌面固定于左侧；900px 以下改为带遮罩的菜单。页面使用 `clamp()` 和断点重排，表格保留独立滚动。数据以文本节点呈现，输入有标签，错误与成功反馈可由辅助技术读取。

## 品牌与资源

- 主色 `#2B7FD8`，强调 `#F4D758`，危险操作 `#E84A5F`。
- 背景 `#FEFCF6` 与 `#FAF6EB`。
- 中文标题 Noto Serif SC：本地字体子集，独立 OFL 许可。
- 正文使用本地系统字体，不向字体服务发送浏览请求。
- 图标和品牌图案由本项目编写，全部随 Worker 打包。
- 署名 Brclio；保留 cmliu/edgetunnel 来源和 GPL 入口。

## 交互原则

1. 配置状态来自真实接口；没有用虚构在线节点数或流量作展示。
2. 未配置用量服务时显示未配置状态，不等于零请求。
3. 主配置、地址列表和可选凭据独立保存；页面提示对应的保存范围。
4. 重置、清除和丢弃未保存内容有确认；错误不能伪装成成功。
5. 订阅和 UUID 默认遮挡，复制与下载由用户触发。
6. 尊重 `prefers-reduced-motion`；功能内容即时可见。

功能与浏览器检查结果见 [validation.md](validation.md)。本设计文档不代表线上 Cloudflare 连接已验收。
